家务小当家 使用教程

把家务变成 RPG —— 每个任务都有血条，血条空了就是脏了，做完回满还掉金币。
这份文档基于 v0.6.3 简体中文版界面撰写，所有按钮名与界面文案一致。

先搞懂三件事

1. 血条（任务健康度）

每个家务任务都有一条 0–100% 的血条。刚做完是 100%，之后随时间线性下降，降到 0 就是该做了。

100% 刚做完
62% 还行
15%

下降速度 = 100 ÷ 清洁频率。频率设 7 天的话，每天掉约 14 点，第 7 天刚好归零。
想让某个任务催得更勤，就把频率调小（比如 2 天）。

新建任务如果状态是「待清洁」 血条一开始就是 0%，会立刻出现在今日任务里。若那里本来就干净，记得把当前状态改成「已清洁」，否则你会一进门被一堆任务砸脸。

2. 金币

完成任务得金币，数量只跟难度（1–5 级）挂钩，默认如下：

难度默认金币典型家务
1 级5 金币拍松抱枕、清空桌面
2 级10 金币倒垃圾、整理床铺
3 级15 金币洗碗、地面吸尘
4 级20 金币刷洗马桶、擦窗户
5 级25 金币大扫除类重活

这张表管理员可以在「设置 → 各难度金币数」里改。

3. 三级结构

房间 → 任务 → 完成记录。房间健康度是它下面所有任务血条的平均值，房屋健康度又是所有房间的平均值。所以首页那个大圆环，本质就是「你家现在有多干净」。

5 分钟上手

  1. 注册第一个账号。打开应用，点「创建账号」，填用户名、显示名称、密码。
    ⚠️ 第一个注册的账号会自动成为管理员，之后注册的默认是普通成员。家人别抢这一步。
  2. 进「房间」页 → 添加房间。会让你先选类型（厨房 / 卧室 / 卫浴 / 客厅 / 书房 / 车库 / 洗衣房）。选好后可以起自定义名字，比如「二楼卫生间」。
  3. 勾模板任务。系统会按房间类型列出预置家务清单（全套 100 条），勾选你要跟踪的。不用全选——选 8–15 条比选 40 条更容易坚持下去。
  4. 给每个任务设三件事：
    • 当前状态 —— 现在是「待清洁」还是「已清洁」（决定初始血条）
    • 难度 —— 1–5 级，决定金币
    • 频率 —— 每 N 天 / 周 / 月做一次，决定血条下降速度
  5. 点「创建房间」。回到首页就能看到今日任务了。
不用一次做到完美 房间的任务可以事后在房间详情页用「模板」按钮继续往里加，也能手打「添加任务」；类型选错了还能改。先跑起来，住一阵子之后再回来调频率和难度。

页面导览

页面看什么 / 干什么
首页房屋健康度大圆环、今日任务清单（按紧急程度排序）、最近动态、我的目标、连击天数。右上角金币数点一下直接跳奖励页。
房间所有房间卡片 + 各自健康度，分良好 / 需要打理 / 告急三档，一眼看全。也能在这里建「区域」做二次分组。
排行榜本周 / 本月 / 本季度 / 今年的积分排名 + 连击榜。关掉游戏化后此页会消失。
日历按月看哪些天完成了多少家务，以及接下来即将到期的任务。
动态谁在什么时候做了什么、拿了多少积分的时间流。在这里可以「取消完成」误点的任务。
奖励奖励目录 + 我的兑换记录。攒够金币点「兑换」。
成就24 个徽章墙 + 家庭整体进度。
个人资料改头像（字母 / 角色 / 上传照片）、改语言、改密码、退出登录。
设置管理员专区。详见后文。

完成任务

两种方式：

  • 首页 —— 今日任务卡片上有完成按钮，点一下即可。
  • 房间详情页 —— 任务行右侧的「已完成」按钮。适合补记、提前完成。
几个容易踩的坑
  • 同一个任务一天只能完成一次。再点会提示「你今天已经完成过这个任务了」。
  • 如果一个任务是「先到先得」模式，别人做完了你再点，会提示「今天已经有其他人完成这个任务了」——这是设计如此，防止重复领币。
  • 点错了去 动态 页，那条记录上有「取消完成」。
  • 严格模式下孩子点了完成不会立刻生效，状态变成「已完成提交，等待管理员审批」，管理员批准后才有金币。

连击（Streak）

每天完成至少 1 个任务，连击 +1；断一天清零。连击天数显示在首页顶部，也是成就的主要来源。

要出门？开假期模式 设置 → 假期模式（可全局，也可按成员单独开）。开启后血条停止下降、连击不会被打断，回来后一切都还好好的，不用重新攒。

任务怎么分

每个任务都可以指定由谁负责。不指定就是「所有人」，谁都能做。

不指定（所有人）

默认。大家都能做，做完大家皆大欢喜。

指定成员

绑定到具体某个人，首页会出现在他的「我的」筛选里。

分配给「孩子」组

一次性把任务派给所有 child 角色的人。

协作任务的金币怎么分

被多人共同负责的任务，金币分配有四种模式：

模式金币归属适合场景
先到先得谁先完成，全部金币归他抢着干、能激起速度的活
共同分担金币在所有负责人之间平摊两个人一起搬沙发这种
自定义按你设的百分比分出力明显不均时
轮值按顺序轮流，界面显示「轮到你了」/「等待某某」洗碗这种每天一轮的经典家务
轮值模式特别适合洗碗 不用再争论今天该谁洗——系统会按顺序点名，页面上直接显示当前该谁。

金币

怎么赚

  • 完成任务 —— 按难度 5 / 10 / 15 / 20 / 25 金币（管理员可改）
  • 达成个人目标 —— 额外拿到「完成奖励」金币

怎么花

奖励页 → 选想要的奖励 → 兑换 → 等管理员批准 → 拿到现实世界的奖励。

管理员能手动调

设置 → 家庭 → 每个成员有「调整」按钮，可以直接加减余额。孩子帮忙做事但没对应任务时，用这个补币最方便。

成就（24 个）

完成数量

1 次「第一步」→ 10 次「小帮手」→ 25 次「忙碌的小蜜蜂」→ 50 次「清洁英雄」→ 100 次「家务冠军」→ 250 次「家务小当家 传奇」→ 500 次「势不可挡！」

连击

3 天「火力全开」→ 7 天「连击大师」→ 14 天「双周勇士」→ 30 天「月度机器」→ 60 天「夜猫子计划员」→ 100 天「百连战神」

金币积累

50「存钱罐」→ 100「储蓄达人」→ 500「寻宝猎人」→ 1,000「黄金大师」→ 5,000「百万富翁」

房间 & 周期

同时保持 3 个房间良好「房间驯服者」、5 个「家居之光」；一个周末完成 5 项「周末勇士」；一周 15 项「超级一周」；每天不断「完美一周」；再来 4 个完美周「完美一月」

解锁时会弹通知（如果开了通知推送）。成就页显示家庭整体完成进度，可以拿来互相激励。

奖励兑换

管理员：先建奖励目录

  1. 设置 → 奖励目录 → 「添加预设奖励」（8 个开箱即用的）
  2. 或手动「创建」：填名称、描述、所需金币

预设奖励包括：电影之夜选择权、冰淇淋奖励、晚睡 30 分钟、游戏时间奖励、决定晚餐、公园探险、免做家务券、家庭桌游。

成员：兑换流程

  1. 奖励页 → 挑一个你能买得起的 → 点「兑换」
  2. 弹窗二次确认「用 XX 金币兑换「XX」？」→ 确认
  3. 状态变成待处理，管理员收到通知
  4. 管理员在设置 → 奖励申请里批准 / 驳回
  5. 驳回会自动退还金币，自己也可以「取消」未处理的申请
建议 初期别把奖励定价太高。一上来「买 Switch」要 5000 金币，孩子算完发现要洗一年碗，直接摆烂。先放几个几十金币的小奖励，让他尝到闭环的甜头。

角色与权限

角色能做什么
管理员改全部设置、增删奖励、批审批和教育、调整金币、改别人角色、导出数据
成员完成任务、看排行榜、兑换奖励、改自己的资料。新人默认是这个
孩子同成员，但在严格模式下完成的任务需管理员批准才生效

改角色：设置 → 家庭 → 家庭成员 → 对应成员 → 角色下拉。至少要留一个管理员。

设置详解（管理员）

常规

项目作用
主题暖橙 / 浅蓝 / 浅玫 / 夜间四套配色
假期模式暂停血条下降。可全局开，也可按成员单独开并设置返程日期
参与任务关掉的话这个人不赚金币、不进排行榜、不出现在目标里。适合只做协作不算分的人
严格模式孩子标记完成 → 需管理员审批。适合刚开始监督孩子
审批入口：设置 → 待审核任务
游戏化关掉后排行榜、连击、成就、奖励、金币全部消失，退化成纯任务跟踪。适合「情侣模式」——两个人不需要被评分
允许新用户注册建完家庭账号后建议关掉，避免陌生人注册

各难度金币数

自定义 1–5 级难度各自的金币值。想拉开差距就设成 1/5/10/20/50 这种指数型，让重活真的值钱。改错了点「使用默认值」还原。

成员目标

给每个孩子设「目标金币 + 周期 + 达成后的额外奖励」。达成后自动发奖励币，首页「我的目标」可以看到进度条。

目标要和现实能对上 一个月目标 200 金币 = 约 20 个 2 级任务。听起来不多，但分摊到每天就是差不多一天一个。设完自己先走一遍，别拍脑袋填数字。

通知

支持两个通道，可同时开：

  • Telegram —— 找 @BotFather 建机器人拿令牌，再把你的会话 ID 填进去（必须是数字 ID，需要先跟机器人发过一条消息）
  • ntfy —— 填服务器地址 + 主题名即可推到手机，私有主题再填访问令牌

可单独勾选提醒类型：任务到期提醒 / 奖励申请 / 成就解锁。设完点「发送测试通知」验证。

推送文案目前是英文 服务端通知走的是独立模板，不跟随界面语言。介意的话只能等后续版本支持。

备份与恢复

设置 → 数据：

  • 导出 —— 下载一份 JSON 备份，包含房间、任务、成员、记录全部数据
  • 导入 —— 上传 JSON 恢复
导入会覆盖现有数据 迁移服务器或重做系统时用。平时数据位置：data/jiawu.db（Docker 里是挂出来的卷），定期把这个文件备份走才是正经做法——JSON 导出适合搬家，不适合当日常备份。

常见问题

任务做完就不再出现了？

正常。频率 7 天的任务，做完后约第 7 天才重新回到今日任务。不是 bug，是血条还没掉下来。去房间详情页可以看到「下次到期」。

首页空空荡荡，什么都没有？

先检查三件事：① 有没有建房间（房间页）；② 房间里有没有勾任务；③ 那些任务的当前状态是不是设成了「已清洁」——全设成已清洁，第一天当然没活干。

全部房间一夜之间变「告急」？

大概率是你假期回来忘了关假期模式，或者反过来——血条按真实时间算过了。检查设置里的假期开关和返程日期。

显示成了 key 名（比如 dashboard.title）？

某个界面文案在这个语言下漏翻了。英文不受影响，切回 English 即可正常显示。

用户自己创建的任务不会跟着变中文？

是的。translationKey 只对系统预置的 100 条家务生效，自建任务永远显示你输入的原始文字。这是设计如此，不是 bug。

忘了管理员密码怎么办？

设置环境变量 ADMIN_RESET_PASSWORD 后重启服务端，会强制重置管理员密码。Docker 部署的话加进 .env 再 docker compose restart。

改了语言没生效？

在个人资料页改语言后，记得点底部「保存」。另外设置页里那个语言下拉是管理员给别人改的，改不了你自己。

为什么排行榜/成就页面打不开？

「游戏化」开关被关掉了（情侣模式）。管理员在设置里重新打开即可。

关于简体中文版

本项目原版支持英 / 法 / 德 / 西 / 意 / 荷六种语言，简体中文（zh）由社区增补，共 646 条词条，是目前翻译最完整的语言包。

本次改动一并修复的问题

  • 语言列表原本在 4 个页面各写一遍，容易漏配 —— 已统一到注册表
  • 日历页和房间页原本漏了荷兰语的日期区域格式 —— 收拢后自动修好
  • Nunito 字体库中文字形缺失导致回退到宋体 —— 已加中文字体回退链（苹方 → 冬青黑 → 微软雅黑 → Noto Sans CJK SC）

已知限制

  • 服务端通知文案仍是英文 —— Telegram / ntfy 推送不跟随语言设置
  • Home Assistant 集成界面尚无中文翻译
  • 原版语言包本身也有漏翻：法语 22 条、意大利语 18 条、荷兰语 17 条、德语 16 条、西语 15 条（多为后来新加的功能）
